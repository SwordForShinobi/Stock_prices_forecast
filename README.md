# ⛽ Stock Prices Forecast

**Прогнозирование цен на нефтепродукты на Санкт-Петербургской международной товарно-сырьевой бирже (СПбМТСБ)**

Streamlit-приложение для прогноза цен на бензин и дизельное топливо на **30 дней вперёд** на основе макроэкономических показателей и ансамбля моделей машинного обучения.

---

## 🚀 Функциональность

- **Прогноз по 4 продуктам:**
  - АИ-92
  - АИ-95
  - АИ-98
  - ДТ (дизельное топливо, реализация)
- **Ввод макроэкономических параметров:** цена Brent, курс доллара, ключевая ставка, инфляция, биржевые индексы MOEX10/MOEXOG и др.
- **Автоматический расчёт производных показателей:** Indicativ, Price_exp, Dempfer, Transit_price, Brent/WTI спред
- **Интерактивный график** прогноза на Plotly
- **Экспорт результатов** в Excel (прогноз + входные данные)

## 🧠 Как это работает

1. Пользователь выбирает нефтепродукт в боковом меню.
2. Заполняет макроэкономические параметры (цена Brent, курс USD, ключевая ставка и т.д.).
3. Приложение рассчитывает производные признаки:
   - **Indicativ** — индикативная цена из справочника по годам
   - **Price_exp** — экспортная цена (netback) с учётом транзита
   - **Dempfer** — демпфирующая надбавка (формула: `max((Price_exp - Indicativ) × коэффициент, 0)`)
   - **Transit_price** — стоимость транзита в рублях
4. Из ZIP-архива загружаются **30 предобученных моделей** (по одной на каждый день прогноза).
5. Каждая модель делает предсказание цены на соответствующий день.
6. Результат отображается в виде таблицы и интерактивного графика.

### Модели

Для каждого продукта используется свой набор моделей, упакованный в ZIP-архив в папке `models/`:

| Продукт | Архив моделей | Количество моделей |
|---------|--------------|-------------------|
| АИ-92   | `ai92_models.zip` | 30 |
| АИ-95   | `ai95_models.zip` | 30 |
| АИ-98   | `ai98_models.zip` | 30 |
| ДТ      | `dt_models.zip`   | 30 |

Модели сериализованы через `pickle` и используют различные наборы признаков в зависимости от горизонта прогноза (первые дни — один набор фич, дальние дни — расширенный).
